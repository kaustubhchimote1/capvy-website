

## Live Indian-market data request

The user requested real-time SENSEX values and a directory of every active IPO-listed Indian equity. No compatible live NSE/BSE feed, provider API documentation, account credentials or CAPVY display/simulation rights are configured, so the current prototype does not claim to display live prices or the full active-company universe. On Saturday, 17 October 2026, BSE's latest official SENSEX close was **74,729.27**, up **413.66 (+0.56%)**, at 16 October 2026 16:00 IST; this is a dated last close, not a live Saturday trade. TradingView's widget-specific market list offers BSE end-of-day data but does not list NSE, so that widget cannot satisfy the live all-India requirement. Global Datafeeds documents live NSE/BSE APIs, but its published terms limit use to a single subscriber's charting/analysis and prohibit simulation applications without exchange/SEBI approval; those terms have not been shown to permit CAPVY's intended use. Do not scrape exchange websites or expose a personal feed. Before integration, obtain API documentation and written subscriber rights permitting real-time public website display and CAPVY's educational/simulation context, then provide any required credentials through the secure project input flow.
